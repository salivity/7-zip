How to Calculate Checksums in 7-Zip File Manager

7-Zip File Manager includes a built-in feature that allows you to calculate cryptographic hashes and checksums directly from its graphical interface without needing external utilities or command-line commands. Verifying checksums ensures that downloaded or transferred files are authentic, intact, and free from corruption. This guide explains how to quickly generate CRC-32, CRC-64, SHA-1, and SHA-256 hash values for any file or folder directly inside the 7-Zip File Manager.

Step 1: Open 7-Zip File Manager and Locate the File

Launch the 7-Zip File Manager application on your computer. Use the built-in directory browser to navigate to the folder containing the file or folder you want to verify. Click on the item to select it. You can also select multiple files simultaneously by holding Ctrl or Shift.

Step 2: Open the Checksum Menu

Once the target file is highlighted, access the checksum tool using one of two methods:

  • Menu Bar: Click on the File menu at the top-left of the window and hover over CRC.
  • Context Menu: Right-click the selected file directly inside the 7-Zip window and hover over CRC.

Step 3: Choose a Hash Algorithm

A sub-menu will appear displaying the available checksum algorithms:

  • CRC-32: Fast, lightweight verification typically used to detect accidental file corruption.
  • CRC-64: An extended version of CRC-32 offering higher collision resistance.
  • SHA-1: A legacy 160-bit cryptographic hash function.
  • SHA-256: A secure, standard 256-bit hash algorithm widely used for software verification.
  • * (Asterisk): Computes all supported algorithms simultaneously.

Select the specific algorithm required to match your verification source, or select * to generate all values at once.

Step 4: View and Copy the Checksum

After selecting the algorithm, 7-Zip will process the file and display a Checksum information pop-up window containing the resulting hexadecimal string.

To copy the calculated hash for comparison against an official checksum:

  1. Highlight the text in the dialog box and press Ctrl + C, or click the Copy button if available.
  2. Paste the value into a text editor or compare it directly against the hash provided by the file distributor. If the values match exactly, the file has not been altered or corrupted.
