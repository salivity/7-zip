How to Fix 7-Zip Context Menu Missing After Update

Updating 7-Zip can occasionally cause its context menu entries to vanish from the Windows right-click menu due to failed DLL registrations, permission conflicts, or altered program settings. This guide provides quick, actionable methods to restore the missing 7-Zip context menu, ranging from adjusting internal application settings to re-registering the shell extension and restarting Windows Explorer.

Method 1: Re-enable the Context Menu in 7-Zip Options

The most common cause is the installer resetting the shell integration setting.

  1. Open the Start menu, search for 7-Zip File Manager, right-click it, and select Run as administrator.
  2. Click Tools in the top menu and select Options.
  3. Navigate to the 7-Zip tab.
  4. Check the box for Integrate 7-Zip to shell context menu. If it is already checked, uncheck it, click Apply, check it again, and click Apply.
  5. Select the context menu items you want displayed in the list below.
  6. Click OK and close the application.

Method 2: Restart Windows Explorer

Windows Explorer frequently caches shell extensions, preventing newly updated context menu handlers from appearing until the process restarts.

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Under the Processes tab, locate Windows Explorer.
  3. Right-click Windows Explorer and select Restart.
  4. Right-click any file to see if the 7-Zip options have reappeared.

Method 3: Check the Windows 11 Modern Context Menu

Windows 11 groups third-party shell extensions under an extra menu layer by default unless the application uses the new Windows 11 API.

  • Right-click a file and click Show more options (or press Shift + F10) to check if 7-Zip is located in the classic context menu.
  • If you recently updated to 7-Zip version 22.00 or newer, ensure you installed the standard 64-bit MSI or EXE package, which includes native Windows 11 context menu support.

Method 4: Manually Re-Register the 7-Zip Shell Extension DLL

If the context menu still does not appear, the shell extension dynamic link library (7-zip.dll) may have failed to register with the Windows Registry during the update.

  1. Press the Windows key, type cmd, right-click Command Prompt, and select Run as administrator.

  2. For 64-bit Windows running 64-bit 7-Zip, run the following command:

    regsvr32 "C:\Program Files\7-Zip\7-zip.dll"

  3. If using 32-bit 7-Zip on 64-bit Windows, run:

    regsvr32 "C:\Program Files (x86)\7-Zip\7-zip.dll"

  4. A dialog box should appear confirming that DllRegisterServer in 7-zip.dll succeeded. Click OK.

Method 5: Perform a Clean Reinstallation

If files from the previous version caused a conflict during the update, perform a clean install:

  1. Open Settings > Apps > Installed apps and uninstall 7-Zip.
  2. Reboot your computer to clear any lingering locked files.
  3. Download the latest installer that matches your operating system architecture (download the x64 installer for 64-bit Windows).
  4. Run the installer as an administrator and complete the setup.
