Can 7-Zip Extract Inno Setup Installers?

Standard installations of 7-Zip cannot directly extract payload files from Inno Setup installer executables, but they can do so when supplemented with specialized third-party plugins. This guide explains why default 7-Zip installations fail to extract these archives, how to enable the feature using a plugin, and which alternative extraction tools provide the most reliable results.

The Limitation of Default 7-Zip

When you open an Inno Setup .exe file using standard 7-Zip, the program treats the file as a generic Portable Executable (PE). As a result, 7-Zip only extracts minor embedded resources such as the installer icon, manifest files, and the setup stub. The actual compressed software payload remains inaccessible because Inno Setup packages its data inside proprietary formats and script tables that the default 7-Zip decompression engine cannot interpret.

Enabling Inno Setup Extraction in 7-Zip

To extract the actual contents of an Inno Setup installer directly within 7-Zip, you must install an Inno Setup plugin.

  1. Obtain a 7-Zip plugin based on the innounp library (such as the Inno Setup plugin for 7-Zip).
  2. Locate your 7-Zip installation directory, typically located at C:\Program Files\7-Zip.
  3. Create a subfolder named Formats if it does not already exist.
  4. Copy the plugin dynamic link library file into the Formats folder.
  5. Restart 7-Zip.

Once configured, opening or extracting the installer inside 7-Zip will display the true application payload, typically mapped to internal directories such as {app}, {sys}, and {tmp}.

Dedicated Alternatives

If you prefer not to modify your 7-Zip installation, standalone unpackers designed specifically for Inno Setup provide direct extraction without setup:

  • InnoExtract: A fast, multi-platform, open-source tool that unpacks installers created by Inno Setup versions 1.2.10 through the latest releases without requiring administrative privileges or the original installer logic to run.
  • Innounp: The standard command-line Inno Setup Unpacker upon which most third-party tools and plugins are built, capable of listing and retrieving all embedded data using basic terminal commands.
