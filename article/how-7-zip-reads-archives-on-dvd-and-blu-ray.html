How 7-Zip Reads Archives on DVD and Blu-Ray

This article explains how the 7-Zip compression utility processes archive files stored on optical storage media such as DVDs and Blu-Ray discs. It covers how the software communicates with optical file systems, manages read-only constraints, handles hardware latency, and navigates multi-part split volumes distributed across physical media.

Operating System File Access

7-Zip does not interact directly with the laser hardware of an optical drive. Instead, it relies on the host operating system to handle physical device communication. When a DVD or Blu-Ray disc is inserted, the operating system mounts the disc using standard optical file systems—typically ISO 9660 or Universal Disk Format (UDF). Once mounted, the operating system presents the optical drive as a read-only volume. 7-Zip accesses archives on the disc using standard file input/output system calls, opening files strictly with read permissions (GENERIC_READ on Windows).

Read-Only Handling and UI Restrictions

Because standard recorded optical media is physically or logically write-protected, 7-Zip automatically enforces read-only behavior:

  • Extraction and Testing: 7-Zip can test archive integrity and extract files to an external writable target (such as an internal SSD or hard drive).
  • Write Prevention: Any commands that require modifying an archive—such as adding files, deleting contents, or updating compression metadata—are disabled in the 7-Zip interface or rejected at the system level with an access denied error.
  • Temporary File Creation: If a user views a file directly from an optical archive, 7-Zip decompresses that specific file into the local operating system's temporary directory rather than writing any data back to the disc.

Seek Latency and Header Parsing

Optical drives feature significantly slower seek times and lower transfer rates than magnetic disks or solid-state storage. 7-Zip handles this through its indexing structure:

  • Central Directory Parsing: Formats like standard .7z and .zip store directory metadata in centralized headers. For .7z, the header is typically located at the end of the archive. 7-Zip instructs the operating system to seek directly to the tail of the file to read the file list into local RAM.
  • Sequential Extraction: Once the archive structure is loaded into memory, 7-Zip reads data streams sequentially whenever possible. This minimizes mechanical laser head movement across the optical tracks, preventing buffer underruns and maintaining maximum read throughput.

Multi-Volume Disc Spanning

Optical discs are frequently used to store large backups split into segments (e.g., archive.7z.001, archive.7z.002). When extracting a multi-volume archive that spans multiple DVDs or Blu-Rays, 7-Zip expects the entire sequence to be available. If the next segment is located on a different physical disc, 7-Zip pauses extraction and prompts the user to specify the path to the next volume, allowing the user to swap discs and resume extraction seamlessly.

Direct Disc Image Parsing

In addition to extracting files from mounted physical discs, 7-Zip contains internal parsers for ISO and UDF image formats. If a user creates a raw disk image of a DVD or Blu-Ray disc (an .iso file), 7-Zip can open the image container directly like any standard archive, enabling file extraction without the need to mount the image in a virtual drive.
