Deploy 7-Zip Silently Across Enterprise Windows

This guide covers the necessary steps to deploy 7-Zip silently across enterprise Windows environments, focusing on the available installer formats, silent installation switches, and common deployment methods including Microsoft Intune, SCCM, and Group Policy. By following these standardized procedures, system administrators can automate the installation, configuration, and maintenance of 7-Zip across all managed endpoints without user interruption.

Choosing the Right Installer

7-Zip provides two installer types for 64-bit and 32-bit Windows systems: the native Windows Installer package (.msi) and the self-extracting executable (.exe).

For enterprise environments, the MSI installer is the recommended format because it provides standardized installation behavior, native integration with Active Directory Group Policy, built-in logging capabilities, and simplified management through modern configuration management tools.

Silent Installation Switches

The required command-line arguments depend on the installer type being deployed.

MSI Installer Switches

To install the MSI package silently without prompting the user or forcing an immediate reboot, execute:

msiexec.exe /i "7z-x64.msi" /qn /norestart
  • /i: Specifies the path to the installation file.
  • /qn: Sets the user interface level to "Quiet with no UI".
  • /norestart: Prevents the computer from restarting after installation completes.

To generate a verbose installation log for troubleshooting, append the logging switch:

msiexec.exe /i "7z-x64.msi" /qn /norestart /L*V "C:\Windows\Temp\7zip_install.log"

EXE Installer Switches

If using the executable file, use the /S flag. The switch is case-sensitive:

7z2301-x64.exe /S

To specify an alternative installation directory with the executable, append the /D parameter at the end of the command:

7z2301-x64.exe /S /D="C:\Program Files\7-Zip"

Deployment Methods

1. Microsoft Intune (Endpoint Manager)

  1. Sign in to the Microsoft Intune admin center.
  2. Navigate to Apps > Windows > Add.
  3. Under App type, select Line-of-business app (for raw .msi) or package it as a Windows app (Win32) using the Microsoft Win32 Content Prep Tool.
  4. If using Win32 App:
    • Install command: msiexec /i "7z-x64.msi" /qn /norestart
    • Uninstall command: msiexec /x {ProductCode} /qn /norestart
    • Detection rules: Set the rule type to File and specify the path C:\Program Files\7-Zip and file 7z.exe, or use MSI with the corresponding Product Code.
  5. Assign the application to target device or user groups.

2. Group Policy (GPO)

  1. Place the .msi file in a network-accessible share with read permissions for the Domain Computers group.
  2. Open the Group Policy Management Console (GPMC) and create or edit a GPO linked to the target Organizational Unit (OU).
  3. Navigate to Computer Configuration > Policies > Software Settings > Software installation.
  4. Right-click Software installation, select New > Package, and browse to the UNC path of the MSI file (e.g., \\Server\Share\7z-x64.msi).
  5. Choose Assigned deployment. The package will install automatically when target computers boot up.

3. PowerShell Deployment Script

For environments using remote execution tools, task sequences, or custom scripts, the following PowerShell script runs the silent installation and verifies success:

$installerPath = "\\NetworkShare\Deploy\7z-x64.msi"
$arguments = "/i `"$installerPath`" /qn /norestart"

$process = Start-Process -FilePath "msiexec.exe" -ArgumentList $arguments -Wait -PassThru

if ($process.ExitCode -eq 0) {
    Write-Output "7-Zip installed successfully."
} else {
    Write-Error "7-Zip installation failed with exit code $($process.ExitCode)."
}

Configuring File Associations

7-Zip does not automatically register file associations when installed silently. To associate formats like .zip, .7z, and .rar across enterprise machines:

  1. Manually configure the preferred file extensions on a reference machine via Default Apps in Windows Settings.

  2. Export the default associations file using DISM:

    dism /online /export-defaultappassociations:"C:\Temp\CustomAssociations.xml"

  3. Edit the XML to retain only the desired archive associations.

  4. Deploy the exported XML file enterprise-wide via Group Policy under: Computer Configuration > Administrative Templates > Windows Components > File Explorer > Set a default associations configuration file.

Silent Uninstallation

To remove 7-Zip silently across endpoints:

  • For MSI deployments:

    msiexec.exe /x "7z-x64.msi" /qn /norestart

    Or via the Registry Product Code:

    msiexec.exe /x {ENTER-PRODUCT-GUID-HERE} /qn /norestart

  • For EXE deployments:

    "C:\Program Files\7-Zip\Uninstall.exe" /S
