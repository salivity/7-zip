How to Completely Remove 7-Zip from Windows

Standard uninstallation of 7-Zip often leaves behind context menu entries, temporary extraction caches, and configuration settings in the Windows Registry. This guide provides a direct, step-by-step procedure to completely uninstall 7-Zip, purge its residual shell integration keys, and delete all associated temporary files from your system.

Step 1: Uninstall 7-Zip via Windows Settings

  1. Press Windows Key + I to open Settings.
  2. Navigate to Apps > Installed apps (or Apps & features on Windows 10).
  3. Search for 7-Zip in the list.
  4. Click the three dots next to it (or click the program name) and select Uninstall.
  5. Follow the on-screen prompts to complete the base removal.

Step 2: Delete Residual Program and User Data Folders

After running the uninstaller, manually verify and delete any leftover application directories:

  1. Press Windows Key + R, type C:\Program Files\7-Zip, and press Enter. If the folder exists, delete it.
  2. If you ran a 32-bit version on a 64-bit OS, check C:\Program Files (x86)\7-Zip and delete it if present.
  3. Press Windows Key + R, type %APPDATA%, and press Enter. Look for a folder named 7-Zip and delete it.

Step 3: Clear 7-Zip Temporary Files

When 7-Zip extracts archives directly into other applications via drag-and-drop, it caches files in the Windows temporary directory.

  1. Press Windows Key + R, type %TEMP%, and press Enter.
  2. Look for folders prefixed with 7z (such as 7zE... or 7zO...).
  3. Delete these folders. You can also safely delete all files in the %TEMP% folder that are not currently in use by other processes.

Step 4: Remove Shell Extensions and Registry Keys

Leftover registry entries cause orphan context menu options and lingering file associations.

Note: Modifying the Windows Registry carries risk. Back up your registry by going to File > Export in the Registry Editor before proceeding.

  1. Press Windows Key + R, type regedit, and press Enter.
  2. Delete the primary configuration keys:
    • Navigate to HKEY_CURRENT_USER\Software\7-Zip and delete the 7-Zip key.
    • Navigate to HKEY_LOCAL_MACHINE\SOFTWARE\7-Zip and delete the 7-Zip key.
  3. Remove shell context menu handlers:
    • Go to HKEY_CLASSES_ROOT\*\shellex\ContextMenuHandlers\7-Zip and delete the 7-Zip key.
    • Go to HKEY_CLASSES_ROOT\Directory\shellex\ContextMenuHandlers\7-Zip and delete the 7-Zip key.
    • Go to HKEY_CLASSES_ROOT\Folder\shellex\ContextMenuHandlers\7-Zip and delete the 7-Zip key.
  4. Search for orphaned CLSID shell entries:
    • Press Ctrl + F while inside the Registry Editor.
    • Search for 7-zip.dll.
    • Delete any associated keys that reference this file path.

Step 5: Restart Windows Explorer

To apply the changes and ensure the context menu completely refreshes:

  1. Press Ctrl + Shift + Esc to launch Task Manager.
  2. Locate Windows Explorer under the Processes tab.
  3. Right-click it and select Restart.
