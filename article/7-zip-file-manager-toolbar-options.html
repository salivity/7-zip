7-Zip File Manager Toolbar Options

The 7-Zip File Manager features a streamlined toolbar positioned directly beneath the main menu bar, offering one-click access to the software's essential file compression, extraction, and management functions. This guide provides a direct breakdown of every toolbar button available in the main interface, detailing what each option does and how it facilitates managing archives and system files.

Add

The Add button opens the "Add to Archive" configuration window for any currently selected files or folders. From this screen, you can specify the destination archive name, select archive formats (such as 7z, ZIP, TAR, or WIM), set compression levels, choose encryption methods, and configure multi-volume splits.

Extract

The Extract button initiates the unpacking process for highlighted archive files. Clicking it opens the "Extract" dialog box, allowing you to choose a target destination directory, specify folder path recreation rules, configure overwrite modes, and input passwords for encrypted archives.

Test

The Test button checks the integrity of the selected archive without actually decompressing the files to your storage drive. 7-Zip verifies the data blocks against their stored checksums (CRC/SHA), alerting you immediately if the archive is corrupted or intact.

Copy

The Copy button opens a dialog prompt allowing you to copy the selected files or folders to a specified directory path on your system. It duplicates the data while leaving the original files in their current location.

Move

The Move button functions similarly to the Copy tool, but relocates the selected files or folders to a new target path entirely, deleting them from the source location upon successful transfer.

Delete

The Delete button removes the selected files, folders, or individual items inside an open archive. Depending on your system settings and whether you are operating on the local file system, items are either sent to the Recycle Bin or deleted permanently.

Info

The Info button displays a detailed properties window for the selected item. For standard files, it shows attributes, timestamps, and sizes. When used on an archive or files within an archive, it displays comprehensive technical data, including packed and unpacked sizes, compression ratios, dictionary sizes, and CRC checksums.
