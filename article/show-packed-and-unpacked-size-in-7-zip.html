Show Packed and Unpacked Size in 7-Zip

7-Zip File Manager allows users to view the uncompressed (unpacked) size and the compressed (packed) size of files side by side directly inside its main interface. This article explains how 7-Zip handles these measurements, where to locate the relevant columns within an archive, and how to arrange them next to each other for easy comparison.

How 7-Zip Displays Size Data

Yes, 7-Zip File Manager can display packed size and unpacked size side by side. When you open any supported archive format (such as .7z, .zip, .rar, or .tar.gz) inside the 7-Zip File Manager interface, the file list displays specific metadata columns for every file and folder contained within that archive:

  • Size: Represents the original, unpacked (uncompressed) size of the file.
  • Packed Size: Represents the compressed size of the file stored inside the archive.

How to View the Columns Side by Side

To view both sizes next to each other, follow these steps:

  1. Open 7-Zip File Manager.
  2. Navigate to and double-click the archive file you want to inspect.
  3. Look at the column headers at the top of the file list (Name, Size, Packed Size, Modified, etc.).
  4. Click and hold the Packed Size column header, then drag it directly next to the Size column header.
  5. Release the mouse button to lock the column in place.

Once moved, 7-Zip will display the original size and the compressed size directly adjacent to each other for every file in the list.

Considerations for Solid Archives

When viewing standard archives (such as standard .zip files), each file displays its distinct packed size. However, if you are viewing a Solid 7z archive, files are compressed together as a single continuous data stream to achieve higher compression ratios. In this case, 7-Zip may display the packed size only for the first file in a solid block, or leave individual packed sizes empty while reporting the total packed size of the entire archive.
