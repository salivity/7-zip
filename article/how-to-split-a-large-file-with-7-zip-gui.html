How to Split a Large File with 7-Zip GUI

Splitting large files into smaller parts is an effective way to bypass email attachment limits, transfer data across multiple storage devices, or upload content to cloud platforms with strict file size caps. This guide demonstrates how to use the 7-Zip graphical interface to break any large file or folder into multi-part archive volumes and explains how to recombine them when needed.

Step 1: Open the 7-Zip Archive Menu

  1. Locate the file or folder you want to split using Windows File Explorer.
  2. Right-click on the file or folder.
  3. Hover over 7-Zip in the context menu and select Add to archive....

Step 2: Configure Archive Settings

In the Add to Archive window that appears:

  1. Archive: Set the destination path and name for your archive by clicking the browse button (...) next to the file name.
  2. Archive format: Choose your preferred format. The .7z format is recommended for higher compression, but .zip can also be used.
  3. Compression level: Select your desired compression level (e.g., Normal or Fast). If you only want to split the file without compressing it to save time, select Store.

Step 3: Set the Split Volume Size

  1. Find the field labeled Split to volumes, bytes: near the bottom-left corner of the window.
  2. You can either select a preset size from the dropdown menu (such as 10M, 650M for CD, or 4092M for FAT32 drives) or enter a custom value manually.
  3. When entering a custom size, use standard size suffixes:
    • K or KB for Kilobytes (e.g., 500000K)
    • M or MB for Megabytes (e.g., 500M)
    • G or GB for Gigabytes (e.g., 2G)

Step 4: Create the Split Volumes

  1. Click OK to begin the process.
  2. 7-Zip will generate sequentially numbered files in the designated folder (for example: filename.7z.001, filename.7z.002, filename.7z.003).

How to Reassemble the Split Files

To restore the original file, ensure all split parts (.001, .002, etc.) are saved in the exact same directory. Right-click exclusively on the first file (.001), hover over 7-Zip, and select Extract Here or Extract to [folder name]. 7-Zip will automatically detect and extract the entire sequence back into the original file.
