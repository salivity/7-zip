Can 7-Zip Open and Extract .Z Files?

Yes, 7-Zip can open and extract files with a single .Z extension natively on Windows. The .Z file extension represents an archive created by the classic Unix compress utility, and 7-Zip supports decompressing this legacy format without requiring any third-party plugins. This guide explains how 7-Zip handles .Z compression, how to extract these files, and the limitations to be aware of.

How 7-Zip Handles .Z Files

The .Z format relies on the LZW (Lempel-Ziv-Welch) compression algorithm. While it is rarely used today for creating new archives, it is still frequently encountered in legacy Unix and Linux environments.

7-Zip supports unpacking (decompression) of the .Z format out of the box. However, it cannot create new .Z archives; support is strictly limited to reading and extracting existing ones.

Steps to Extract .Z Files Using 7-Zip

You can extract a .Z file using either the Windows graphical interface or the command line.

Using the Graphical User Interface (GUI)

  1. Locate the .Z file in Windows File Explorer.
  2. Right-click the file and navigate to the 7-Zip context menu.
  3. Select Extract Here to unpack the contents into the current directory, or choose Extract to "[filename]" to unpack them into a dedicated folder.
  4. Alternatively, select Open archive to view the contents inside the 7-Zip File Manager before extracting.

Using the Command Line

If you use the command-line version (7z.exe), you can extract a .Z file by running:

7z x filename.Z

Handling Combined Extensions (.tar.Z)

In Unix environments, the compress tool only compresses a single file at a time. To archive multiple files, users typically bundled them into a .tar file first, resulting in files named .tar.Z (or shortened to .taz).

If your .Z file is actually a compressed TAR archive:

  1. Extracting the .Z file will produce an uncompressed .tar file.
  2. Right-click the resulting .tar file and extract it with 7-Zip a second time to retrieve the actual folders and individual files.
