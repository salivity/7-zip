Minimize 7-Zip Compression to System Tray

This article explains how 7-Zip handles window minimization during archive creation, clarifies the specific function of the built-in "Background" mode, and details how to send the progress window to the Windows system tray. While 7-Zip includes native tools to reduce system load during large compression tasks, achieving a complete minimization to the system tray requires specific steps or third-party utilities.

Understanding the 7-Zip "Background" Button

When creating an archive, 7-Zip displays a progress window showing elapsed time, remaining time, compression ratio, and speed. Inside this dialog, you will find a dedicated Background button.

Clicking the Background button does not hide the window to the system tray. Instead, it alters how Windows allocates resources to the compression task:

  • CPU Priority Adjustment: It lowers the process priority of 7zG.exe (the GUI process) from "Normal" to "Below Normal" or "Low."
  • System Responsiveness: By dropping the process priority, your system remains responsive for browsing, gaming, or multitasking while 7-Zip utilizes idle CPU cycles.
  • Window State: Once clicked, the button changes to "Foreground" so you can restore normal processing priority at any time.

Native Minimization Behavior

When you minimize the 7-Zip compression window using the standard Windows minimize button (_), the window shrinks down to the main Windows Taskbar, not the system tray (notification area).

By default, 7-Zip does not include native code to dock or hide active compression tasks into the notification area next to the system clock. The task remains visible as an active application icon on the primary taskbar.

How to Minimize 7-Zip to the System Tray

Because 7-Zip lacks a native "minimize to tray" toggle, users who want to clear taskbar clutter during long compression tasks must use a lightweight third-party window management tool. Common utilities that enable this include:

  1. RBTray: A lightweight, background utility that allows you to right-click the minimize button of almost any Windows application (including 7-Zip) to send it directly to the system tray instead of the taskbar. Left-clicking the tray icon restores the window.
  2. Trayconizer: A command-line wrapper that can launch applications directly into the system tray or hook into minimizing actions.
  3. 4t Tray Minimizer: A utility that adds an extra button to the title bar of running programs specifically for sending them to the notification area.

Best Practice for Large Archives

For optimal handling of heavy compression jobs:

  1. Start your compression task in 7-Zip.
  2. Click the Background button in the progress dialog to ensure normal PC usage is not interrupted by high CPU utilization.
  3. Use a tray management tool if you need the taskbar space cleared, or minimize the window to the taskbar to let it finish unobtrusively.
