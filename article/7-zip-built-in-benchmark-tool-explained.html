7-Zip Built-In Benchmark Tool Explained

7-Zip includes a native performance testing feature known simply as the 7-Zip Benchmark. This integrated utility evaluates a computer's processor and memory performance by running intensive compression and decompression cycles using the LZMA algorithm. This guide explains what the utility is, how it measures hardware performance, how to run it via both graphical and command-line interfaces, and why it remains a standard test in hardware reviews.

What Is the 7-Zip Benchmark?

The 7-Zip Benchmark is a free, built-in diagnostic test bundled directly into the 7-Zip file archiver. Rather than requiring third-party testing software, users can immediately measure their CPU’s data handling capabilities within the application. The tool operates by compressing and decompressing randomly generated data entirely in RAM, preventing storage drive speeds (such as SSD or HDD bottlenecks) from skewing the results.

How It Measures Performance

The utility reports performance using MIPS (Million Instructions Per Second) or GIPS (Giga Instructions Per Second), broken down into two distinct phases:

  • Compressing: This phase heavily tests CPU branch prediction, cache speed, and system memory latency. It represents the processing power required to search for patterns and reduce file sizes.
  • Decompressing: This phase is simpler algorithmically but relies heavily on raw integer pipeline throughput and L1/L2 hardware cache performance.
  • Total Rating: A combined average score that provides an overall assessment of the system's multi-core efficiency.

Because the tool can scale across multiple threads, it effectively benchmarks both single-core performance and multi-threaded scaling on modern processors.

How to Run the Benchmark

The utility can be accessed via the graphical interface or the command line:

Using the Graphical User Interface (GUI)

  1. Open the 7-Zip File Manager.
  2. Click on the Tools menu at the top of the window.
  3. Select Benchmark (or press the hotkey assigned by your operating system).
  4. In the pop-up window, configure the Dictionary size and the Number of CPU threads you want to test.
  5. The test will run continuously until you click Stop.

Using the Command Line

You can run the benchmark from the terminal or Command Prompt using the 7-Zip executable:

  • Standard run: 7z b
  • Specify thread count (e.g., 8 threads): 7z b -mmt=8

Why the Benchmark Is Widely Used

Hardware reviewers and overclockers frequently use the 7-Zip Benchmark for several reasons:

  • Zero Cost and Lightweight: It requires no separate purchase, complex installation, or extensive disk space.
  • Stability Testing: Continuous execution pushes CPU cores and system RAM hard enough to expose unstable overclocks or memory timings.
  • Real-World Representation: Unlike purely synthetic benchmarks, it reflects real-world computational workloads involving data compression, integer math, and memory bandwidth.
