How to Enable Dual-Pane in 7-Zip File Manager

7-Zip File Manager includes built-in support for dual-pane folder directory listings, allowing users to view and manage two separate directories side-by-side. This article explains how to activate the dual-panel feature, switch between panes, and use keyboard shortcuts to streamline file transfers and archive management.

How to Turn On Dual-Pane View

By default, 7-Zip opens in a single-pane layout. You can switch to a dual-pane layout using either of the following methods:

  1. Keyboard Shortcut: Open 7-Zip File Manager and press F9 on your keyboard.
  2. Menu Bar: Click View in the top menu and select 2 Panels.

Once enabled, the main window splits vertically into two independent directory browsers.

Working with Dual Panels

The dual-panel interface functions similarly to classic orthodox file managers (such as Total Commander or Norton Commander):

  • Independent Navigation: Each pane can browse different locations simultaneously, including local drives, external storage, network shares, or the contents of compressed archive files.
  • Active Panel Focus: Only one panel is active at a time, denoted by the highlighted address bar and selected items. Press the Tab key to instantly toggle focus between the left and right panels.
  • Quick Transfers: You can drag and drop files directly between the two panes. Alternatively, you can use built-in function keys:
    • F5 (Copy): Copies selected files from the active pane to the folder currently open in the inactive pane.
    • F6 (Move): Moves selected files from the active pane to the target folder in the inactive pane.

How to Disable Dual-Pane View

To revert to the single-pane view, press F9 again or navigate to View and click 1 Panel. 7-Zip will retain the path of the currently active pane as your primary view.
