7-Zip Windows 11 Context Menu Integration

When Windows 11 introduced a streamlined context menu, legacy applications were hidden behind the extra "Show more options" layer. This article explores how 7-Zip introduced native support for Windows 11's modern right-click layout, the technical mechanisms behind this implementation, and how you can ensure the utility appears directly on your primary context menu without extra clicks.

The Challenge of the Modern Context Menu

Windows 11 replaced the classic Windows shell menu with a modern, touch-friendly, and simplified design. Legacy applications originally integrated into File Explorer using the IContextMenu COM interface. In Windows 11, Microsoft relegated all extensions relying on IContextMenu to a secondary menu accessible only by selecting "Show more options" or pressing Shift + F10. This change added friction for frequent 7-Zip users who relied on quick, one-click archiving and extraction.

Technical Implementation in 7-Zip

To bridge this gap, developer Igor Pavlov updated 7-Zip (starting with versions 21.07 beta and finalized in 22.00) to adhere to Microsoft’s new context menu standards:

  1. IExplorerCommand Interface: The modern context menu requires the use of the IExplorerCommand COM interface rather than the older IContextMenu. This API runs more asynchronously and natively aligns with Windows 11's performance guidelines.
  2. Sparse Packages: Windows 11 mandates that modern context menu extensions possess a Package Identity, typically delivered via an MSIX package. Because 7-Zip is a traditional Win32 application, it utilizes a "sparse package" registration. This grants the traditional executable the required identity without forcing the entire program into a sandboxed Universal Windows Platform (UWP) container.

How to Enable the Modern Integration

To get 7-Zip directly on the top-level Windows 11 menu:

  1. Update 7-Zip: Ensure you are running 7-Zip version 22.00 or newer. Download and run the 64-bit installer (.exe), which includes the modern shell integration.
  2. Default Installation: The installer automatically registers the modern shell extension package with Windows.
  3. Verify Settings:
    • Open 7-Zip File Manager.
    • Navigate to Tools > Options.
    • Under the 7-Zip tab, ensure Integrate 7-Zip to shell context menu is checked.
    • Customize which actions (such as "Extract Here", "Extract to {Folder}", or "Add to {Archive}.7z") you want visible.

Interacting with the Modern Menu

Once installed, right-clicking on any compatible file or directory immediately displays 7-Zip on the primary menu. Hovering over or clicking the 7-Zip entry opens an inline submenu containing your configured compression and extraction shortcuts, eliminating the need to visit the legacy menu entirely.

If the modern entry fails to appear immediately after installation, restarting explorer.exe via Task Manager or rebooting the PC will force Windows 11 to reload its package registrations.
