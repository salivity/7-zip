How to Test Archive Integrity in 7-Zip

Testing archive integrity ensures your compressed files are not corrupted, truncated, or damaged before you attempt extraction or long-term storage. 7-Zip File Manager includes a dedicated, built-in feature that verifies archive checksums directly from the main toolbar without needing to extract the contents to your hard drive.

Steps to Test an Archive

  1. Open 7-Zip File Manager
    Launch the 7-Zip File Manager application from your Start menu or desktop shortcut.

  2. Locate the Archive
    Use the built-in directory browser to navigate to the folder containing your archive file (such as .zip, .7z, or .rar).

  3. Select the File
    Click once on the archive file to highlight it.

  4. Click the Test Button
    On the top toolbar, click the Test button, which is represented by a blue checkmark icon.

  5. Review the Results
    A progress window will scan the file's contents against its internal checksums. Once the scan finishes:

    • Success: A prompt will appear stating, "There are no errors."
    • Failure: An error log will display specific issues, such as "Data Error", "CRC Failed", or "Unexpected end of data", indicating file corruption.

Testing Individual Files Inside an Archive

If you only want to verify specific files within a large compressed package:

  1. Double-click the archive inside 7-Zip to view its internal file structure.
  2. Hold Ctrl or Shift and click the specific files or folders you want to check.
  3. Click the Test button on the toolbar. 7-Zip will only verify the selected items.
