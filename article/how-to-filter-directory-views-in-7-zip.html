How to Filter Directory Views in 7-Zip

Filtering directory views in the 7-Zip File Manager allows you to quickly locate specific files and isolate formats within large archives or dense folders. While 7-Zip does not feature a dedicated live-filter search bar like modern operating system explorers, you can effectively filter directory contents using the built-in Search function, the Wildcard Selection feature, and the Flat View display mode.

Method 1: Using the Built-in Search Tool

The primary way to filter and view only matching files within the current directory and its subfolders is through the Search utility.

  1. Open 7-Zip File Manager and navigate to the target directory or archive.
  2. Press Alt + F7 on your keyboard (or click File > Search).
  3. In the Search field, enter your filter criteria using standard wildcards:
    • To view all images: *.jpg or *.png
    • To view files containing a specific word: *report*
  4. Choose whether to check the Subfolders option depending on if you want to include nested directories.
  5. Click OK. 7-Zip displays a filtered list containing only the items that match your parameters.

Method 2: Filtering with Selection Masks

If you want to isolate or operate on specific items directly inside the standard folder view without opening a separate search window, use wildcard selections.

  1. Inside the directory, press the Plus key (+) on your numeric keypad (or click Edit > Select...).
  2. Enter the file extension or pattern you want to isolate (for example, *.pdf or data*.*).
  3. Click OK. 7-Zip will automatically highlight only the matching files.
  4. Press Ctrl + I (or click Edit > Invert Selection) if you need to select everything except your filtered pattern to quickly delete or move unneeded files.

Method 3: Enabling Flat View for Global Filtering

Standard folder hierarchies hide files inside subfolders. Enabling Flat View removes the folder tree structure so you can view and sort all files in one continuous list.

  1. Navigate to the top level of the archive or folder you want to inspect.
  2. Click View in the top menu bar.
  3. Select Flat View.
  4. Click the column headers (such as Extension, Size, or Modified) to group similar files together instantly across the entire directory structure.
