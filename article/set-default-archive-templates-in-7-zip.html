Set Default Archive Templates in 7-Zip

This guide explains how to customize and establish default archive creation settings in 7-Zip File Manager. While 7-Zip does not feature a dedicated "profiles" menu like some competitors, you can set persistent default compression parameters through the graphical interface's memory, deploy Windows Registry files for specific configurations, or build dedicated context-menu templates using the 7-Zip command-line tool.

Method 1: Setting Persistent Defaults in the GUI

7-Zip automatically saves the parameters used during your last compression task as the default baseline for future archives.

  1. Open 7-Zip File Manager.
  2. Select any file or folder and click the green Add button (or press Alt + Enter) to open the Add to Archive dialog.
  3. Configure your preferred default options:
    • Archive format: Choose between 7z, zip, tar, or wim.
    • Compression level: Set your standard level (e.g., Normal, Maximum, or Ultra).
    • Compression method: Select LZMA2, Deflate, or your preferred algorithm.
    • Dictionary size and Word size: Adjust according to your typical system memory availability.
    • Encryption: Set a default algorithm (AES-256) if applicable.
  4. Click OK to execute the compression.

7-Zip writes these choices to the Windows Registry under HKEY_CURRENT_USER\Software\7-Zip\Compression. The next time you open the Add to Archive window, these settings will load automatically as your default template.

Method 2: Creating Reusable Template Profiles via Registry

If you switch between different compression standards (for example, a high-compression archive profile versus a quick-store profile), you can back up and swap configurations using Registry files.

  1. Set up your desired template options using Method 1 and complete an archive creation.

  2. Press Win + R, type regedit, and press Enter.

  3. Navigate to:

    HKEY_CURRENT_USER\Software\7-Zip\Compression

  4. Right-click the Compression folder and select Export.

  5. Save the file with a recognizable name, such as 7Zip-Ultra-Template.reg.

  6. Repeat the process in 7-Zip for another profile (such as 7Zip-Fast-Zip.reg).

Double-clicking any of your exported .reg files before archiving will instantly switch 7-Zip's default settings to that saved configuration.

Method 3: Building One-Click Template Shortcuts

To create distinct templates that bypass the 7-Zip interface entirely, use the Windows Send To menu paired with 7z.exe.

  1. Press Win + R, type shell:sendto, and press Enter.

  2. Right-click an empty space, choose New > Shortcut.

  3. In the location field, enter your command-line template using the path to your 7-Zip installation:

    "C:\Program Files\7-Zip\7z.exe" a -t7z -mx=9 -m0=lzma2 -md=64m "%~1.7z"
    • -t7z: Sets the format to 7z.
    • -mx=9: Applies Ultra compression.
    • -m0=lzma2: Sets the compression method to LZMA2.
    • -md=64m: Sets the dictionary size to 64MB.

  4. Click Next, name the shortcut (e.g., Compress with Ultra Template), and click Finish.

You can now right-click any file in Windows, navigate to Send to, and apply that specific compression template instantly.
