Viewing Hidden Files and Paths in 7-Zip

7-Zip File Manager can display hidden files and access system folder paths directly. Unlike Windows File Explorer, which hides certain directories and files by default, 7-Zip automatically reveals these items without requiring complex configuration changes. This article explains how 7-Zip handles hidden items, how to navigate directly to system paths, and what permissions are required to access protected areas of your operating system.

Default Handling of Hidden and System Files

By default, 7-Zip File Manager does not hide files marked with the Hidden or System attributes. When you open any directory in 7-Zip, it lists all contained items regardless of the view settings configured in Windows File Explorer. This includes operating system files like desktop.ini, ntuser.dat, and hidden directories such as AppData or $Recycle.Bin.

Because 7-Zip acts as an independent file browser, it reads the file system directly rather than filtering the output through the Windows shell's visibility rules.

Navigating to System Folder Paths

You can navigate to system folder paths within 7-Zip in multiple ways:

  1. Address Bar Entry: Click on the address bar at the top of the 7-Zip interface, type or paste the full directory path (such as C:\ProgramData or C:\Windows\System32), and press Enter.
  2. Environment Variables: You can type standard environment variables directly into the path bar, such as %temp% or %appdata%, to jump immediately to user-specific hidden system folders.
  3. Directory Tree: Expand the folder structure using the main pane or the folder tree pane (enabled via View > Folders History or standard folder navigation) to drill down manually into system-level directories.

Administrator Privileges and Access Restrictions

While 7-Zip displays hidden files automatically, it remains subject to Windows file system permissions (NTFS Access Control Lists).

If you attempt to open a protected system path—such as C:\System Volume Information or another user's profile folder—you may encounter an "Access is denied" error. To browse and modify contents in these restricted locations, you must run 7-Zip with elevated privileges. Right-click the 7-Zip File Manager shortcut and select Run as administrator before navigating to protected system directories.
