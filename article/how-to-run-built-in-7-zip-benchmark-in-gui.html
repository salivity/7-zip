How to Run Built-In 7-Zip Benchmark in GUI

The built-in 7-Zip benchmark utility is a lightweight tool that measures your computer's CPU performance during data compression and decompression tasks. This guide explains how to open the graphical interface of 7-Zip, launch the benchmark tool, adjust its test parameters, and interpret the resulting performance scores.

Step 1: Open 7-Zip File Manager

Open the Start menu on your computer, search for 7-Zip File Manager, and launch the application. Ensure you open the File Manager itself rather than clicking an archive context menu option.

Step 2: Launch the Benchmark Tool

Once the 7-Zip File Manager window is open:

  1. Click on Tools in the top menu bar.
  2. Select Benchmark from the dropdown menu (or press the hotkey assigned to it, typically the benchmark shortcut or accessing it directly via the menu).

Step 3: Configure Benchmark Settings

A new benchmark window will appear and immediately begin testing. You can adjust the following settings in the upper section of the window:

  • Dictionary size: Sets the memory load for the test. Larger dictionary sizes require more RAM. The default is typically 32 MB.
  • CPU threads: Sets how many processor threads to utilize. By default, 7-Zip selects the maximum available threads for your processor.

Changing either option will restart the benchmark automatically with the new parameters.

Step 4: Interpret the Results

The benchmark runs continuously in two primary phases:

  • Compressing: Tests the CPU's speed and latency when compressing data.
  • Decompressing: Tests the CPU's processing power when unpacking data.

Results are displayed in Speed (KB/s), CPU Usage (percentage), and Rating measured in MIPS (Million Instructions Per Second). The Total Rating at the bottom provides an overall measurement of your hardware's performance.

Step 5: Stop the Benchmark

The benchmark runs continuously until stopped. Click the Stop button to pause the test, or click Close to exit the benchmark window when you are finished.
