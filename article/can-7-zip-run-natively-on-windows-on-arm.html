Can 7-Zip Run Natively on Windows on ARM?

7-Zip runs natively on ARM-based Windows devices, offering full 64-bit ARM (ARM64) architecture support. This article explains the availability of native ARM64 builds for 7-Zip, the performance benefits over emulation, and how to get the correct version for your Windows on ARM PC.

Native ARM64 Support in 7-Zip

7-Zip officially supports Windows on ARM through a dedicated 64-bit ARM64 installer. Starting with version 21.01 alpha and continuing through all current stable releases, Igor Pavlov, the developer of 7-Zip, added native compilation for the ARM64 platform.

This means users with devices powered by Qualcomm Snapdragon processors—such as the Surface Pro 11, Surface Pro X, Lenovo ThinkPad X13s, and Snapdragon X Elite laptops—do not need to rely on Windows' built-in x86 or x64 emulation layers to extract or compress files.

Benefits of Running 7-Zip Natively

Running the native ARM64 version of 7-Zip provides several distinct advantages over running the standard x86 or x64 versions under emulation:

  • Superior Compression and Decompression Speed: Native execution allows 7-Zip to take direct advantage of ARM instruction sets without the translation overhead caused by emulation, resulting in faster archiving speeds.
  • Lower CPU and Memory Overhead: Emulation consumes additional system resources. The native binary operates leaner, which preserves system responsiveness during heavy archive extraction.
  • Better Battery Efficiency: Because the CPU works more efficiently without translation layers, performing large archive operations consumes less battery power.

How to Install the Native ARM64 Version

To ensure you are running 7-Zip natively on an ARM-powered Windows laptop or tablet, download the appropriate installer:

  1. Navigate to the official 7-Zip download page.
  2. Look for the link explicitly labeled 64-bit Windows ARM64.
  3. Download the executable installer (typically named 7zXXXX-arm64.exe, where XXXX represents the version number).
  4. Run the installer and follow the standard on-screen prompts.

Once installed, 7-Zip integrates directly into Windows Explorer, providing seamless, high-performance file compression built specifically for your device's architecture.
