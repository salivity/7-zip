Convert ZIP to a Smaller 7z Archive Using 7-Zip

7-Zip can significantly reduce the file size of an existing ZIP archive by recompressing its contents into the proprietary .7z format. While the software does not provide an automated "one-click" conversion button, unpacking the original ZIP file and repacking the raw data with 7-Zip’s advanced compression algorithms typically produces an archive that is 30% to 70% smaller than the original.

Why 7z Archives Are Smaller Than ZIP Files

Standard ZIP archives rely predominantly on the older Deflate compression algorithm, which compresses each file individually using a relatively small dictionary size (usually 32 KB).

In contrast, the .7z format uses the LZMA and LZMA2 algorithms, which offer several distinct advantages:

  • Larger Dictionary Sizes: 7-Zip can use dictionaries spanning from several megabytes up to multiple gigabytes, allowing the algorithm to find repeating patterns across large files.
  • Solid Compression: Unlike standard ZIP files, 7-Zip can group multiple similar files into a single, continuous data block (solid archive). This allows it to identify shared data patterns between different files, dramatically reducing redundant data across entire folders.

How to Recompress a ZIP to 7z in 7-Zip

To achieve maximum compression, follow these steps using the 7-Zip graphical interface:

  1. Extract the ZIP Archive: Open the .zip file in 7-Zip or your system file manager and extract all contents to a temporary folder. Simply placing the .zip file inside a .7z container will not save space; the raw files must be extracted first.
  2. Open the Compression Menu: Select all the extracted files, right-click, choose 7-Zip, and click Add to archive....
  3. Configure Archive Settings:
    • Archive format: Select 7z.
    • Compression level: Set to Ultra for the highest compression ratio.
    • Compression method: Choose LZMA2.
    • Dictionary size: Set to 64 MB or higher (depending on your available system RAM).
    • Solid Block size: Set to Solid to allow cross-file pattern matching.
  4. Create the Archive: Click OK to begin the process.

What Kind of Size Reduction to Expect

The final archive size depends entirely on the type of files contained inside the archive:

  • Text files, source code, and executables: These yield the highest compression gains. Recompressing these from ZIP to 7z frequently cuts the archive size in half.
  • Redundant datasets: If the archive contains multiple versions or backups of the same files, solid compression will drastically shrink the overall footprint.
  • Pre-compressed media: Formats like JPEG, MP3, MP4, and modern Office documents (.docx, .xlsx) are already compressed. Recompressing them into 7z will produce minimal to no size difference.
