Can 7-Zip Extract APFS Disk Images?

Standard 7-Zip cannot extract or read files directly from APFS (Apple File System) image dumps. While 7-Zip is a versatile archive utility that supports older Apple formats like HFS and HFS+, it currently lacks native support for the modern APFS architecture introduced by Apple in 2017. Attempting to open an APFS-formatted .dmg, .raw, or .img file in standard 7-Zip will either result in an error or display an unreadable, raw partition block without access to individual files.

Why 7-Zip Does Not Support APFS

7-Zip includes unpackers for standard disk containers (such as ISO, VHD, and basic DMG) and older Mac filesystems like HFS/HFS+. However, APFS functions very differently from its predecessor:

  • Container Architecture: APFS groups multiple virtual volumes within a shared storage container, dynamically allocating disk space rather than using static partition sizes.
  • Complex Metadata: APFS relies on copy-on-write mechanisms, complex B-tree structures, and proprietary inode allocation schemes.
  • Proprietary Specifications: Apple has not released an open, complete public specification for APFS implementation on third-party operating systems, limiting open-source integration into utilities like 7-Zip.

Because the official 7-Zip codebase has not integrated an APFS file system parser, the software can sometimes recognize the outer container wrapper (such as a DMG disk image), but it cannot interpret the underlying APFS filesystem to list or extract the files within it.

What Happens When You Try

If you load an APFS disk dump into 7-Zip:

  1. Unrecognized Format: If the image is a raw .dd or .img dump, 7-Zip will typically return a "Cannot open file as archive" error.
  2. Raw Partition Output: If the image is inside a .dmg container, 7-Zip may open the outer wrapper and show a numbered partition file (such as 0.fat or a generic raw image), but opening that internal file fails to display the actual directory tree and files.

Alternatives to Extract APFS Image Dumps

To inspect and extract files from an APFS disk image, use specialized tools designed for modern Apple file systems:

  • On macOS: Mount the disk image natively using Disk Image Mounter or through the Terminal using the command hdiutil attach image.dmg. macOS natively reads and writes to APFS images without extra software.
  • On Windows: Use dedicated APFS-compatible utilities:
    • Paragon APFS for Windows: Mounts APFS storage devices and disk images directly into Windows Explorer with full read capabilities.
    • UFS Explorer or R-Studio: Professional data recovery tools that can reconstruct, parse, and extract directory structures directly from APFS disk image dumps.
    • 7-Zip Plugins / Forks: Some experimental community-built plugins attempt to parse basic APFS structures, but they are not fully stable or part of the standard 7-Zip release.
  • On Linux: Use the open-source apfs-fuse driver to mount the image dump in read-only mode, enabling standard file extraction via the Linux terminal or file manager.
