7-Zip Keyboard Shortcuts for Fast File Management

7-Zip File Manager fully supports a wide range of keyboard shortcuts designed for rapid file manipulation and archive administration. By relying on standard function keys and classic file manager conventions, 7-Zip enables users to browse directories, manage archives, copy, move, and inspect files without ever reaching for a mouse. This guide details whether 7-Zip supports these hotkeys, outlines the most critical shortcuts for file manipulation, and demonstrates how to maximize your workflow efficiency.

Does 7-Zip Support Keyboard Shortcuts?

Yes. 7-Zip File Manager natively supports standard keyboard navigation and file operation shortcuts. Built in the tradition of classic dual-pane file utilities like Norton Commander and Total Commander, 7-Zip assigns core file management commands directly to the standard function keys (F1 through F9) and common Windows modifier combinations.

Essential Function Key Shortcuts

The function row serves as the backbone for file manipulation in 7-Zip:

  • F3 (View): Opens the selected file in the internal viewer or the viewer designated in your settings.
  • F4 (Edit): Opens the selected file in the configured text editor. Inside an archive, saving changes in the editor prompts 7-Zip to immediately update the archive.
  • F5 (Copy): Copies selected files. In single-pane mode, it prompts for a destination path; in dual-pane mode, it defaults to the directory open in the opposite pane.
  • F6 (Move): Moves selected items to a specified destination or the opposite pane.
  • F7 (New Folder): Creates a new directory in the current path.
  • F8 or Delete: Moves selected files or folders to the Recycle Bin, or deletes them from an archive.
  • Shift + Delete: Permanently deletes selected files, bypassing the Windows Recycle Bin.
  • F9 (Two Panels): Toggles between single-pane and dual-pane views.

Navigation and Selection Shortcuts

Moving through folders and archives quickly relies on standard movement keys:

  • Enter: Opens the selected folder or archive.
  • Backspace: Moves up one directory level.
  • Alt + Up Arrow: Navigates up one folder level (alternative to Backspace).
  • Ctrl + A: Selects all files and folders in the active pane.
  • Gray + (Numpad Plus): Opens a dialog to select items matching a wildcard pattern (e.g., *.zip).
  • Gray - (Numpad Minus): Deselects items matching a wildcard pattern.
  • Gray * (Numpad Asterisk): Inverts the current selection.
  • Tab: Switches focus between panels when dual-pane mode (F9) is active.
  • Alt + F1 / Alt + F2: Changes the drive for the left panel or right panel, respectively.

Speeding Up Archive Manipulation

Using keyboard shortcuts inside 7-Zip transforms how you manage compressed files. By pressing F9 to enable two-panel mode, you can display an open archive on one side and a local folder on the other. Highlighting files in the archive and pressing F5 instantly extracts them to the destination pane, while pressing F5 on the local pane compresses and adds files directly into the open archive.
