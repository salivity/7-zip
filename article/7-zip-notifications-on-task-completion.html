7-Zip Notifications on Task Completion

When 7-Zip finishes compressing or extracting an archive, it provides minimal built-in feedback rather than prominent alerts. By default, 7-Zip features no native completion sound, and its primary visual signal is simply the automatic disappearance of the progress window upon successful completion. This guide details the exact visual cues, sound behavior, and methods to implement custom alerts when operations finish.

Visual Notifications in 7-Zip

7-Zip relies on a lightweight interface that avoids intrusive visual pop-ups. During and immediately after an operation, the application triggers the following visual signals:

  • Progress Window Auto-Close: During a task, a progress window displays elapsed time, remaining time, compression ratio, and a percentage bar. Once the operation reaches 100% without issues, this window automatically closes. The sudden closing of the window is the primary indication that the task is finished.
  • Taskbar Progress Indicator: On modern versions of Windows, the 7-Zip taskbar icon reflects real-time progress using a green overlay bar. When the task finishes successfully, the green fill reaches the end and the taskbar icon vanishes along with the main process.
  • Error and Warning Prompts: If an operation encounters an issue—such as a corrupted archive, locked file, or insufficient disk space—the progress window does not close. Instead, it remains open and displays a log listing the specific errors, requiring manual dismissal by clicking "Close."

Sound Notifications in 7-Zip

7-Zip does not include any native sound effects for successful task completion.

  • Successful Operations: The software operates entirely silently. There are no built-in settings or configuration menus within the 7-Zip Graphical User Interface (GUI) to enable a chime, beep, or sound effect when extraction or compression completes.
  • System Error Sounds: If a fatal error occurs that generates a standard Windows message box, Windows may play its default "Critical Stop" or "Asterisk" sound based on your active Windows Sound Scheme settings. However, this is managed by the operating system, not 7-Zip itself.

How to Get Completion Alerts Using the Command Line

Because the standard 7-Zip GUI lacks native audio cues, users who require sound notifications often run tasks using the 7-Zip command-line tool (7z.exe) within a batch file or PowerShell script.

Adding an Audio Alert via Batch Script

You can append an audio chime to a command-line operation by utilizing PowerShell's built-in sound function immediately after the command executes:

7z x archive.zip -o"C:\Destination" && powershell -c "[console]::beep(1000,500)"

Adding a Visual Pop-up Notification

To trigger a distinct visual dialog when an extraction completes, you can use the Windows msg command or a PowerShell pop-up box:

7z x archive.zip -o"C:\Destination" && powershell -c "Add-Type -AssemblyName PresentationCore,PresentationFramework; [System.Windows.MessageBox]::Show('7-Zip operation completed successfully!')"

In both script examples, the && operator ensures the sound or message box triggers only if the 7-Zip operation finishes with an exit code of 0 (success).
