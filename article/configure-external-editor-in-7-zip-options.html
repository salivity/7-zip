Configure External Editor in 7-Zip Options

By default, 7-Zip uses the basic Windows Notepad to open and edit files directly within compressed archives. Configuring an external text editor, such as Notepad++, Visual Studio Code, or Sublime Text, provides syntax highlighting, advanced search, and better performance when modifying archived documents. This guide walks you through the step-by-step process of setting up your preferred editor inside the 7-Zip configuration settings.

Step-by-Step Configuration

  1. Launch 7-Zip File Manager
    Open the Windows Start menu, search for 7-Zip File Manager, and open the application.

  2. Access Options
    In the top menu bar, click on Tools and select Options... from the dropdown menu.

  3. Navigate to the Editor Tab
    In the Options window, locate the tabs along the top and click on the Editor tab.

  4. Specify the External Editor Path

    • Under the Editor: field, click the ellipsis button (...) to open the file browser.
    • Navigate to the executable (.exe) file of your desired editor. Common examples include:
      • Notepad++: C:\Program Files\Notepad++\notepad++.exe
      • VS Code: C:\Users\<YourUsername>\AppData\Local\Programs\Microsoft VS Code\Code.exe
      • Sublime Text: C:\Program Files\Sublime Text\sublime_text.exe
    • Select the executable and click Open.

  5. Configure a Diff Viewer (Optional)
    On the same screen, you can also define an external comparison tool under the Diff: field (such as WinMerge or Beyond Compare) using the same browsing method.

  6. Save Changes
    Click Apply, then click OK to close the Options window.

Testing the Configuration

To verify that your external editor is active, open any archive file in 7-Zip File Manager, highlight a file inside the archive, and press F4 (or right-click the file and select Edit). The selected file will immediately launch inside your newly configured external program. Any changes saved in the editor will prompt 7-Zip to update the archive automatically.
