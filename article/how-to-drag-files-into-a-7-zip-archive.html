How to Drag Files into a 7-Zip Archive

Adding files directly to an existing archive in 7-Zip can be done in seconds using standard drag-and-drop actions. This guide explains how to drag files from Windows File Explorer straight into an active 7-Zip File Manager window, the settings to confirm during the transfer, and how to fix common issues if the drag-and-drop function is not responding.

Steps to Drag and Drop Files into 7-Zip

  1. Open 7-Zip File Manager: Launch 7-Zip and navigate to the archive (.zip, .7z, etc.) you want to update. Double-click the archive to open its contents inside the 7-Zip window.
  2. Open File Explorer: Open a separate Windows File Explorer window and locate the files or folders you want to add.
  3. Drag the Files: Click and hold the selected files in File Explorer, drag your cursor over the open 7-Zip File Manager window, and release the mouse button.
  4. Confirm the Add Operation: A dialog box will appear asking for confirmation and compression settings (such as compression level or encryption). Leave the defaults or adjust them as needed, then click OK (or Copy).

The files will automatically compress and appear inside your open archive.

Troubleshooting: Why Drag and Drop Might Fail

If you see a "circle with a slash" icon or nothing happens when dropping files, check the following solutions:

  • Privilege Mismatch (Run as Administrator): Windows blocks drag-and-drop between programs running at different security levels. If 7-Zip is running as an Administrator and File Explorer is running as a standard user, the transfer will be blocked. Close 7-Zip and reopen it without administrative privileges.
  • Read-Only Archive Formats: Certain file formats supported by 7-Zip (such as .iso, .rar, .cab, or .dmg) are read-only or proprietary. 7-Zip cannot modify these archives. Ensure your target archive is in an editable format like .7z, .zip, or .tar.
  • File Permissions: Verify that the archive file itself is not marked as "Read-only" in its Windows properties and is not currently open in another program.
