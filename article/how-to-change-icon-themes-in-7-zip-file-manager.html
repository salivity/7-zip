How to Change Icon Themes in 7-Zip File Manager

This guide explains how to customize the visual appearance of 7-Zip File Manager by replacing its default icons with modern themes. Because 7-Zip lacks a native theme engine, changing its toolbar and file-type icons requires using a resource editing tool to directly modify the application's executable and library files.

Prerequisites

To complete this process, you will need:

  • 7-Zip installed on your system.
  • A resource editing utility, such as Resource Hacker.
  • A custom 7-Zip icon pack containing the replacement .ico and .bmp files.
  • Administrative privileges on your computer.

Step 1: Back Up Original Files

  1. Open File Explorer and navigate to the 7-Zip installation directory, typically located at: C:\Program Files\7-Zip\
  2. Locate 7zFM.exe (7-Zip File Manager) and 7z.dll.
  3. Copy both files to a secure location to serve as a backup in case you need to revert changes.

Step 2: Replace Toolbar Icons in 7zFM.exe

  1. Launch your resource editing tool (e.g., Resource Hacker) as an Administrator.
  2. Click File > Open and select C:\Program Files\7-Zip\7zFM.exe.
  3. In the left panel, expand the Bitmap folder.
  4. Locate the resource folders named TOOLBAR or numbered IDs that correspond to the toolbar strip (typically IDs such as 100, 101, or 102 containing the button strip image).
  5. Right-click the target bitmap resource and select Replace Bitmap... (or Action > Replace Resource).
  6. Click Open file with new bitmap..., select your custom replacement bitmap from your icon pack, and click Replace.
  7. Go to File > Save to apply the modifications.

Step 3: Replace File Association Icons in 7z.dll

To change the archive icons displayed in Windows File Explorer (such as .7z, .zip, and .rar files):

  1. In Resource Hacker, click File > Open and open C:\Program Files\7-Zip\7z.dll.
  2. In the left sidebar, expand the Icon Group folder.
  3. You will see several numbered groups (e.g., 0, 1, 2), which correspond to the default icons assigned to specific archive types.
  4. Right-click an icon group and select Replace Icon....
  5. Click Open file with new icon..., choose your replacement .ico file, and click Replace.
  6. Repeat this process for each icon group you wish to update.
  7. Click File > Save to save the changes to 7z.dll.

Step 4: Refresh the Windows Icon Cache

  1. Open Task Manager by pressing Ctrl + Shift + Esc.
  2. Locate Windows Explorer under the Processes tab, right-click it, and select Restart.
  3. If the newly assigned icons do not appear immediately, clear the Windows icon cache by opening the Run dialog (Win + R), typing ie4uinit.exe -show, and pressing Enter.

Once completed, open 7-Zip File Manager to view your updated toolbar icons and inspect your archive files in Windows Explorer to confirm the new design has taken effect.
