Extract EXT2, EXT3, and EXT4 Images with 7-Zip

7-Zip natively supports opening and extracting raw files from EXT2, EXT3, and EXT4 partition images without requiring Linux environments or specialized mounting software. This utility can treat these raw Linux filesystem dumps as standard archives, allowing Windows users to browse, view, and extract internal files and folders directly to their local storage.

How 7-Zip Handles EXT Partitions

7-Zip includes built-in parsers for various filesystem formats, including the Linux Extended Filesystem family (EXT2, EXT3, and EXT4). When you create a raw sector-by-sector image of a partition—typically generated using tools like the Linux dd command or disk imaging utilities—7-Zip treats that binary image just like a .zip or .7z archive.

Supported raw image extensions generally include:

  • .img
  • .raw
  • .dd
  • Files without extensions or generic binary dumps containing an EXT superblock.

Steps to Extract Files

  1. Locate the Image File: Ensure your image is a direct, uncompressed raw partition dump.
  2. Open with 7-Zip: Right-click the image file, navigate to the 7-Zip context menu, and select Open archive. If the context menu does not recognize the extension, open the 7-Zip File Manager manually, locate the file, and double-click it.
  3. Browse the Contents: 7-Zip displays the root directory hierarchy of the Linux filesystem, including standard directories such as /etc, /home, and /var.
  4. Extract: Select the specific files or folders you need, click the Extract button, choose your destination folder, and confirm.

Technical Considerations and Limitations

  • Read-Only Access: 7-Zip can only read and extract data from EXT images. It cannot modify, add, or delete files inside an EXT2, EXT3, or EXT4 image.
  • Full Disk Images vs. Partition Images: If the raw file is a full disk image containing a partition table (MBR or GPT) rather than a single partition dump, 7-Zip will usually open the file and display each partition as an individual item (e.g., 0.ext, 1.fat). You must double-click the specific EXT partition inside 7-Zip to access its files.
  • Linux Permissions and Symlinks: When extracting to an NTFS or FAT32 filesystem on Windows, standard Linux permissions (POSIX permissions), ownership, and symbolic links may be lost or converted into standard text files or empty shortcuts.
  • Compression and Encryption: 7-Zip handles uncompressed raw dumps. If the image is compressed with tools like gzip or xz (e.g., .img.gz), you must first decompress the container to access the underlying .img file. Encrypted partitions (such as LUKS) cannot be read by 7-Zip directly.
