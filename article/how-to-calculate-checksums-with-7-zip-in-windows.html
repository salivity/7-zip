How to Calculate Checksums with 7-Zip in Windows

Yes, 7-Zip allows you to calculate file and folder checksums directly from Windows Explorer using its built-in context menu integration. This guide explains how to generate hash values such as CRC-32, CRC-64, SHA-1, and SHA-256 without opening the full 7-Zip application, how to configure the context menu if the option is missing, and how to use these values to verify file integrity.

Steps to Generate Checksums in Windows Explorer

Once 7-Zip is installed, it integrates into the Windows shell menu by default. Follow these steps to generate a hash:

  1. Open Windows Explorer and locate the file or folder you want to verify.
  2. Right-click the item. On Windows 11, select Show more options to display the classic context menu if necessary.
  3. Hover your cursor over the CRC SHA entry (or the 7-Zip submenu, depending on your settings).
  4. Select the specific algorithm you need:
    • CRC-32
    • CRC-64
    • SHA-1
    • SHA-256
    • * (Calculates all available algorithms at once)
  5. A window will appear showing the calculated hash string. You can select and copy this value directly to your clipboard.

How to Enable the CRC SHA Context Menu

If the "CRC SHA" option does not appear in your right-click menu, enable it through 7-Zip settings:

  1. Open the 7-Zip File Manager.
  2. Navigate to Tools in the top menu and select Options.
  3. Go to the 7-Zip tab.
  4. Ensure the Integrate 7-Zip to shell context menu box is checked.
  5. In the list of context menu items below, place a checkmark next to CRC SHA > and the specific algorithms you want displayed.
  6. Click Apply, then OK.

Verifying File Integrity

To confirm that a downloaded file has not been altered or corrupted, compare the output generated by 7-Zip with the official hash provided by the file source. If the two strings match character-for-character, the file is authentic and intact.
