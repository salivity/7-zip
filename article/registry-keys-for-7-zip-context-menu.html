Registry Keys for 7-Zip Context Menu

This article covers the specific Windows Registry keys responsible for enabling, registering, and configuring 7-Zip's context menu integration. Managing these keys allows administrators and power users to troubleshoot missing context menu options, automate deployments, or customize which 7-Zip entries appear when right-clicking files and folders in Windows Explorer.

1. Shell Extension Handler Keys

To display context menu entries for files, directories, and folders, Windows relies on dynamic shell extensions. 7-Zip registers its Context Menu Handler under the following locations in HKEY_CLASSES_ROOT (or HKEY_CURRENT_USER\Software\Classes / HKEY_LOCAL_MACHINE\SOFTWARE\Classes):

  • All Files:
    HKEY_CLASSES_ROOT\*\shellex\ContextMenuHandlers\7-Zip
    • Default value: {23170F69-40C1-2702-0000-000000000000}
  • Directories:
    HKEY_CLASSES_ROOT\Directory\shellex\ContextMenuHandlers\7-Zip
    • Default value: {23170F69-40C1-2702-0000-000000000000}
  • Folders (Virtual and File System):
    HKEY_CLASSES_ROOT\Folder\shellex\ContextMenuHandlers\7-Zip
    • Default value: {23170F69-40C1-2702-0000-000000000000}

Deleting or clearing the default value of these keys removes the 7-Zip entry from the right-click menu for those respective targets.

2. CLSID and DLL Registration

The GUID {23170F69-40C1-2702-0000-000000000000} points Windows Explorer to the 7-Zip shell extension dynamic link library (7-zip.dll).

  • CLSID Path:
    HKEY_CLASSES_ROOT\CLSID\{23170F69-40C1-2702-0000-000000000000}
  • InprocServer32:
    HKEY_CLASSES_ROOT\CLSID\{23170F69-40C1-2702-0000-000000000000}\InprocServer32
    • Default value: Full path to 7-zip.dll (e.g., C:\Program Files\7-Zip\7-zip.dll)
    • ThreadingModel: Apartment
  • Approved Shell Extensions:
    HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Shell Extensions\Approved
    • String Value Name: {23170F69-40C1-2702-0000-000000000000}
    • Value Data: 7-Zip Shell Extension

3. Context Menu Settings and Appearance

7-Zip stores its GUI and context menu display preferences within the user profile hive:

  • Key:
    HKEY_CURRENT_USER\Software\7-Zip\FM

Under this key, several values control how the context menu renders:

  • CascadedMenu (DWORD):
    • 1: Groups all 7-Zip options into a single cascading submenu labeled "7-Zip".
    • 0: Displays 7-Zip commands directly in the root level of the Windows context menu.
  • MenuIcons (DWORD):
    • 1: Enables icons next to commands inside the 7-Zip menu.
    • 0: Disables icons, displaying text only.
  • ContextMenu (DWORD):
    • A bitmask representing which specific operations are displayed (e.g., "Open archive", "Extract files...", "Extract Here", "Add to archive...", "Test archive").
    • Toggling options inside 7-Zip's GUI (Tools > Options > 7-Zip) modifies the hexadecimal value of this DWORD. Setting this value to 0 removes all inner commands.
