7-Zip Compression Levels from Store to Ultra

7-Zip provides six distinct compression levels ranging from Store to Ultra, designed to balance processing speed, resource usage, and final archive size. This guide details each available level, explaining how they work, their impact on system performance, and when to use them for optimal archiving.

1. Store (Level 0)

  • Compression Ratio: None (0%)
  • Speed: Instantaneous
  • Dictionary Size: 0 KB
  • Overview: The Store level does not compress files; it simply packages them into a single archive container. Because the CPU performs no compression algorithms, the process is limited only by your drive's read and write speeds. It is ideal for grouping already-compressed formats (such as JPEG, MP3, MP4, or ZIP) or creating rapid backups without CPU overhead.

2. Fastest (Level 1)

  • Compression Ratio: Low
  • Speed: Very fast
  • Dictionary Size: 64 KB
  • Overview: Fastest applies minimal compression algorithms to reduce file size slightly while maintaining high processing speeds. It requires negligible RAM and CPU power, making it suitable for older hardware, quick file transfers, or large datasets where time is prioritized over disk space.

3. Fast (Level 3)

  • Compression Ratio: Moderate-low
  • Speed: Fast
  • Dictionary Size: 1 MB
  • Overview: Fast provides a slight improvement in compression efficiency over the Fastest setting while still completing tasks quickly. It is an intermediate option when you want smaller files than Store or Fastest provide, but do not want the longer wait times associated with higher settings.

4. Normal (Level 5)

  • Compression Ratio: Standard / Balanced
  • Speed: Moderate
  • Dictionary Size: 16 MB
  • Overview: Normal is the default setting in 7-Zip. It delivers an optimal compromise between compression speed, CPU usage, and output size for everyday use. Most standard file formats (like text documents, executables, and general directories) achieve significant size reduction under this setting with modest memory requirements.

5. Maximum (Level 7)

  • Compression Ratio: High
  • Speed: Slow
  • Dictionary Size: 32 MB
  • Overview: Maximum increases dictionary size and search depth to significantly reduce archive sizes. This setting consumes noticeably more RAM and CPU cycles, resulting in longer compression times. It is best suited for distribution packages, long-term storage, or sending large data sets over bandwidth-constrained networks.

6. Ultra (Level 9)

  • Compression Ratio: Highest possible
  • Speed: Very slow
  • Dictionary Size: 64 MB (or higher depending on configuration)
  • Overview: Ultra utilizes the deepest compression parameters and largest dictionary sizes available in the 7z format. It demands substantial system memory—often several gigabytes depending on thread count—and taxes the processor heavily. Use Ultra when minimizing final file size is critical, such as archiving large databases or software builds for long-term cold storage.
