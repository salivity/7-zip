Set 7-Zip as Default for Compressed Files in Windows

This guide explains how to set 7-Zip as the default application for opening compressed archives (such as ZIP, RAR, and 7Z) in Windows. You will learn the most effective methods to configure these file associations, including using 7-Zip’s built-in options menu with administrative privileges, configuring native Windows Settings, and using File Explorer.

Method 1: Using 7-Zip File Manager (Recommended)

Configuring associations directly within 7-Zip allows you to link multiple archive types simultaneously.

  1. Click the Start menu and type 7-Zip File Manager.
  2. Right-click the application icon and select Run as administrator. (Administrative rights are required to modify system-level file associations).
  3. In the top menu, navigate to Tools > Options.
  4. In the System tab, locate the file extension list.
  5. Click the + button above the column representing your user account or all users to associate all archive formats automatically, or click specific extensions (such as 7z, zip, rar, tar, gz) individually.
  6. Click Apply, then click OK.

Method 2: Using Windows Settings

If you are using Windows 10 or Windows 11, you can assign 7-Zip manually through the operating system's settings.

  1. Press Windows Key + I to open the Settings menu.
  2. Select Apps, then click Default apps.
  3. In the search box under "Set defaults for applications," type 7-Zip and select it from the results.
  4. Locate the file types you want 7-Zip to handle (such as .zip, .7z, and .rar).
  5. Click on each extension and select 7-Zip GUI (or 7-Zip File Manager) from the list, then click Set default.

Method 3: Using the "Open With" Context Menu

You can set associations for individual file types directly from File Explorer.

  1. Right-click any compressed file (e.g., a .zip archive).
  2. Hover over Open with and select Choose another app.
  3. Select 7-Zip File Manager from the list of programs.
  4. Check the box labeled Always use this app to open [file extension] files (on Windows 11, click Always).
  5. If 7-Zip does not appear in the list:
    • Click More apps > Look for another app on this PC.
    • Browse to C:\Program Files\7-Zip\ (or C:\Program Files (x86)\7-Zip\).
    • Select 7zFM.exe and click Open.
