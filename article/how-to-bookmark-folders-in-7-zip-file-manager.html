How to Bookmark Folders in 7-Zip File Manager

Yes, 7-Zip File Manager includes a built-in feature to bookmark frequently accessed folder paths, categorized under the "Favorites" menu. This guide explains how to save directory locations, quickly navigate between them using keyboard shortcuts, and manage your saved folder paths within the 7-Zip interface.

How to Save a Folder Path

To bookmark a directory in 7-Zip File Manager:

  1. Open 7-Zip File Manager.
  2. Navigate to the folder you want to bookmark so that its contents are displayed in the main pane.
  3. Click on the Favorites menu on the top menu bar.
  4. Select Add to Favorites.
  5. Choose an available slot (numbered 0 through 9) to assign your current path to that position.

How to Access Bookmarked Paths

Once a directory is saved, you can jump to it instantly using two methods:

  • Menu Navigation: Click Favorites in the menu bar and select the desired folder from the list.
  • Keyboard Shortcuts: Press the corresponding number key or shortcut assigned to the slot to jump directly to the target directory without opening the menu.

Managing Your Bookmarks

7-Zip File Manager maintains your saved paths in its configuration registry, meaning they will persist every time you open the application. If you need to replace an existing bookmark, simply navigate to the new path, open the Favorites menu, choose Add to Favorites, and overwrite an occupied slot.
