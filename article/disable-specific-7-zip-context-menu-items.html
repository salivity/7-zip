Disable Specific 7-Zip Context Menu Items

Installing 7-Zip automatically adds several commands to the Windows right-click context menu, ranging from simple extraction commands to file testing and compression options. If these multiple entries clutter your menu, you can customize the list to hide commands you rarely use. This guide outlines how to selectively disable specific 7-Zip shell extension context items directly using the built-in settings in 7-Zip File Manager.

Step 1: Open 7-Zip File Manager as Administrator

To ensure your settings apply across the system without permission conflicts, launch the application with elevated privileges:

  1. Press the Windows Key and type 7-Zip File Manager.
  2. Right-click the 7-Zip File Manager shortcut.
  3. Select Run as administrator.

Step 2: Access the Context Menu Settings

Once the application opens:

  1. Click on Tools in the top menu bar.
  2. Select Options from the drop-down menu.
  3. In the Options window, navigate to the 7-Zip tab.

Step 3: Uncheck Unwanted Context Menu Items

Under the Context menu items section, you will see a list of every action 7-Zip can display in Windows Explorer.

  1. Scroll through the list of items, such as:
    • Open archive
    • Extract files...
    • Extract Here
    • Extract to <Folder>
    • Test archive
    • Add to archive...
    • Compress and email...
  2. Uncheck the box next to each command you want to disable.
  3. Leave the items checked that you still wish to see in your context menu.

(Optional) If you want to keep all items grouped together rather than taking up primary space in Windows Explorer, ensure the Cascaded context menu checkbox is enabled.

Step 4: Apply and Save Changes

  1. Click the Apply button in the lower-right corner of the window.
  2. Click OK to close the Options dialog.
  3. Close 7-Zip File Manager.

The changes take effect immediately. Right-click any file or archive in File Explorer to verify that the disabled items have been removed from your context menu.
